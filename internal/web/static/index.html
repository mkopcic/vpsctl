API Reference

Method Endpoint Body / Params Opis
GET /servers — Lista svih servera (bez passworda)
GET /servers/ping — TCP ping svih servera s latencijom
POST /servers/exec {"server":"mellon","command":"uptime"} Izvrsi SSH komandu
POST /servers/update {"server":"all"} System update (apt/yum/apk)
POST /servers/restart {"server":"mellon","service":"nginx"} systemctl restart + is-active
GET /jobs ?server=mellon&limit=20 Job history iz SQLite baze

curl primjeri

# Lista servera
curl http://localhost:8080/servers

# Ping svih
curl http://localhost:8080/servers/ping

# Exec na jednom serveru
curl -X POST http://localhost:8080/servers/exec \
  -H "Content-Type: application/json" \
  -d '{"server":"mellon","command":"uptime"}'

# Update svih servera
curl -X POST http://localhost:8080/servers/update \
  -H "Content-Type: application/json" \
  -d '{"server":"all"}'

# Restart servisa
curl -X POST http://localhost:8080/servers/restart \
  -H "Content-Type: application/json" \
  -d '{"server":"mellon","service":"nginx"}'

# Job history
curl "http://localhost:8080/jobs?limit=10&server=mellon"
